# 操作ガイド（マニュアルPDF）配置フォルダ

ヘルプ画面（`/help`）の「操作ガイドを開く」ボタンは、このフォルダ内の以下のPDFを新しいタブで開きます。

    給与計算DXPro2026-操作ガイド-.pdf

- 製品に同梱の操作ガイドPDFを、上記のファイル名でこのフォルダに配置してください。
- ファイル名は年版に対応します。年版が変わる場合は `Components/Pages/Help.razor` の `ManualUrl` も合わせて更新してください。
- 現行（WinForms版）の `MConst.MANUAL_PASS`（`Documents\給与計算DXPro{年}-操作ガイド-.pdf`）に対応する移植です。
